📌 Django란?
Django는 파이썬 기반으로 만들어진 프레임워크이다. 

 **주요 특징:**
    *   ORM (Object-Relational Mapping): 데이터베이스를 객체처럼 다룰 수 있도록 해줍니다.
    *   템플릿 엔진: 동적인 웹 페이지를 쉽게 생성할 수 있도록 해줍니다.
    *   URL 라우팅: URL과 뷰 함수를 매핑하여 깔끔한 URL 구조를 만들 수 있습니다.
    *   관리자 인터페이스: 데이터베이스 내용을 쉽게 관리할 수 있는 관리자 페이지를 자동으로 생성해줍니다.
    *   보안: 다양한 웹 공격으로부터 보호하기 위한 기능을 제공합니다.

## MTV 패턴이란?

Django는 MTV (Model-Template-View) 패턴을 따르는 디자인 패턴을 사용합니다. 이는 MVC (Model-View-Controller) 패턴과 유사하지만, Django만의 방식으로 구현되었습니다.

*   **Model:** 데이터베이스의 데이터를 표현합니다. 데이터의 구조와 동작을 정의하며, 데이터베이스 테이블과 매핑됩니다.
*   **Template:** 사용자에게 보여지는 부분을 담당합니다. HTML, CSS, JavaScript 등을 사용하여 웹 페이지의 레이아웃과 디자인을 정의합니다.
*   **View:** 모델과 템플릿 사이의 중재자 역할을 합니다. 사용자의 요청을 처리하고, 모델에서 데이터를 가져와 템플릿에 전달하여 사용자에게 보여줄 내용을 결정합니다.
